# Homebrew tap for Mainspring

[Mainspring](https://trymainspring.com) turns 90+ hidden macOS settings into one-click, reversible toggles, each with an undo button.

## Install

```sh
brew install --cask chipmunk1101/mainspring/mainspring
```

Signed and notarized by Apple. macOS 13 Ventura or later, universal (Apple Silicon and Intel).
